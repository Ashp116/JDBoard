# JDBoard docs

The documentation site, built with [Docusaurus](https://docusaurus.io/).

```bash
npm install
npm start          # live preview on http://localhost:3000/JDBoard/
npm run build      # static site in build/
```

Pages are Markdown files in `docs/`; the sidebars are in `sidebars.ts` and the home
page is `src/pages/index.tsx`.
